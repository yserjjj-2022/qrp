# Примеры нормализации (синтетические)

Ниже — учебные примеры для формата ответа. Тексты придуманы для проверки правил
и не взяты из реальных интервью.

## Пример 1. Механический повтор служебного слова

Вход: `Они, они, они на подстраховке`
Выход:
```json
{
  "normalized_text": "Они на подстраховке.",
  "changes": [{"type": "stutter", "from": "Они, они, они", "to": "Они"}],
  "uncertain_spans": [],
  "new_terms": [],
  "asr_quality": "ok"
}
```

## Пример 2. Повтор-обдумывание сохраняется

Вход: `Не знаю, не знаю, вопрос, наверное, в простоте`
Выход:
```json
{
  "normalized_text": "Не знаю, не знаю, вопрос, наверное, в простоте.",
  "changes": [],
  "uncertain_spans": ["не знаю", "наверное"],
  "new_terms": [],
  "asr_quality": "ok"
}
```

## Пример 3. Паразит удаляется, отрицание и маркер остаются

Вход: `Я, ну, не помню, чтобы он ошибался`
Выход:
```json
{
  "normalized_text": "Я не помню, чтобы он ошибался.",
  "changes": [{"type": "filler", "from": "ну", "to": ""}],
  "uncertain_spans": ["не помню"],
  "new_terms": [],
  "asr_quality": "ok"
}
```

## Пример 4. Термин по лексикону

Лексикон содержит каноническую форму `MCP` с вариантом `эсипи`.

Вход: `Подключил эсипи Финам`
Выход:
```json
{
  "normalized_text": "Подключил MCP Финам.",
  "changes": [{"type": "term", "from": "эсипи", "to": "MCP"}],
  "uncertain_spans": [],
  "new_terms": [],
  "asr_quality": "ok"
}
```

## Пример 5. Незнакомый термин остаётся и уходит в new_terms

Вход: `Смотрел квик-дашборд в приложении`
Выход:
```json
{
  "normalized_text": "Смотрел квик-дашборд в приложении.",
  "changes": [],
  "uncertain_spans": [],
  "new_terms": ["квик-дашборд"],
  "asr_quality": "ok"
}
```

## Пример 6. Искажённый фрагмент

Вход: `Там было что-то про <нечитаемо> и лимиты`
Выход:
```json
{
  "normalized_text": "Там было что-то про [неразборчиво] и лимиты.",
  "changes": [{"type": "garbled", "from": "<нечитаемо>", "to": "[неразборчиво]"}],
  "uncertain_spans": [],
  "new_terms": [],
  "asr_quality": "garbled"
}
```

## Пример 7. Незнакомое искажение остаётся, реплика помечается doubtful

Лексикон не содержит ничего похожего на «вертулятор».

Вход: `Поставил вертулятор на сервер, теперь всё считается быстрее`
Выход:
```json
{
  "normalized_text": "Поставил вертулятор на сервер, теперь всё считается быстрее.",
  "changes": [],
  "uncertain_spans": [],
  "new_terms": ["вертулятор"],
  "asr_quality": "doubtful"
}
```

Здесь нельзя подставлять похожее по звучанию слово из своих знаний: смысл
неизвестен, решение принимает человек.

## Пример 8. Два созвучных варианта одного незнакомого слова

Вход: `Гонял через планшир, а потом планширь сломался`
Выход:
```json
{
  "normalized_text": "Гонял через планшир, а потом планширь сломался.",
  "changes": [],
  "uncertain_spans": [],
  "new_terms": ["планшир", "планширь"],
  "asr_quality": "doubtful"
}
```

Обе формы остаются в тексте и обе попадают в `new_terms`: выбрать правильную
из них нельзя, это делает оператор.
