# Привязка блоков «вопрос интервьюера -> ответ респондента» к вопросам гайда

Ты размечаешь транскрипт интервью. Транскрипт уже разбит на блоки: в каждом
блоке сначала идёт реплика (или несколько реплик) интервьюера, затем ответ
респондента. Для каждого блока определи, какой вопрос гайда в нём прозвучал:
основной вопрос, уточнение к уже заданному вопросу или ничего из гайда.

## Вопросы гайда

Формат строки: `идентификатор | группа | формулировка`.

{guide}

## Кандидаты по сходству

Для каждого блока ниже перечислены ближайшие по тексту вопросы гайда. Это
подсказка, а не ответ: сходство слов часто обманывает, а ответ респондента
может увести в сторону.

{candidates}

## Блоки

Формат строки: `номер | ВОПРОС: реплики интервьюера | ОТВЕТ: реплики респондента`.

{blocks}

## Правила

1. Размечай **только блоки** из списка. Номер блока бери буквально, не
   придумывай новый.
2. `question` — идентификатор вопроса гайда, который прозвучал в блоке.
   Идентификатор бери буквально из списка выше.
3. Оценивай пару целиком: короткий вопрос интервьюера («А почему?») без ответа
   респондента непонятен, а ответ респондента показывает тему. Если ответ
   явно относится к вопросу гайда, привязывай блок к нему, даже когда
   формулировка интервьюера отличается от гайда.
4. Несколько реплик интервьюера подряд — один блок и один контекст. Если
   интервьюер задал два вопроса, выбери основной (первый по смыслу) и не
   дроби блок.
5. `question = null` — блок вне гайда: приветствие, переход, организационный
   вопрос, комментарий. Не подставляй «ближайший» вопрос: если темы гайда в
   блоке нет, ответ `null`.
6. `is_probe = true` — уточнение к вопросу, заданному раньше («А почему?»,
   «Что именно?», «Можете привести пример?»). В `question` у уточнения тот же
   идентификатор, к которому оно относится.
7. Порядок вопросов в интервью может отличаться от гайда, вопросы могут
   повторяться и пропускаться. Ориентируйся на смысл, а не на порядок.
8. Блок без ответа респондента (вопрос остался без ответа) тоже размечай.

## Формат ответа

Верни один JSON-объект без пояснений и без markdown-обёртки:

```json
{
  "blocks": [
    {"block": 1, "question": "7Т", "is_probe": false},
    {"block": 2, "question": null, "is_probe": false}
  ]
}
```

`block` — номер блока из списка (целое число).
