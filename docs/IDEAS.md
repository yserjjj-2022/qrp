# IDEAS: идеи для развития

Записываем идеи, которые не входят в текущую спецификацию.

## Расшифровка и нормализация

- **Повторная расшифровка другим ASR-движком (например, Nemotron).** Машинная расшифровка
  местами искажает термины и содержит нечитаемые места; второй движок позволит сравнить
  варианты и выбрать более надёжный фрагмент. В схеме уже есть
  `interview.transcript_source`, поэтому повторная расшифровка не потребует смены модели
  данных. Вне M1.
- **Сравнение версий L2 между движками.** Если появится вторая расшифровка, полезна
  метрика расхождения L1/L2 по репликам, чтобы выбирать движок по данным, а не на глаз.

## Разметка M2

- **Две аннотации вместо одной для кодов A3/4.** Код A3/4 в текущем кодбуке не различает
  подвиды ответственности, поэтому предлагается ставить по нему две аннотации с признаком
  «не различает»: расхождение внутри кода видно в отчёте и не теряется при агрегации.
  Требует уточнения на пилоте, в M1 не входит.
- **Общий признак «код не различает подтипы».** Механизм вместо отдельного правила для
  A3/4: поле у кода, помечающее, что код агрегирует несколько смыслов.
