# Кодирование реплики респондента кодами кодбука

Ты размечаешь интервью по кодбуку. На вход дана одна реплика респондента в
нормализованном виде (L2), разбитая на фрагменты. Нужно присвоить каждому
фрагменту коды из списка ниже — или не присвоить ни одного, если значимого
содержания нет.

## Кодбук

Формат строки: `код | семья | название | определение | включает | исключает | правило при сомнении`.

{codes}

## Вопрос гайда

Вопрос, к которому привязана реплика: {question}

## Что известно про порядок

Перед репликой интервьюер говорил (в порядке транскрипта):

{prior_turns}

## Реплика и её фрагменты

Формат строки: `id_фрагмента | качество распознавания | текст фрагмента`.

{fragments}

## Правила

1. Размечай **только фрагменты из списка**. `fragment_id` бери буквально; новый
   не придумывай. Ответ обязан содержать все фрагменты реплики.
2. Код бери только из кодбука. Не подходящий ни под один код фрагмент получает
   `OTH` с описанием; фрагмент без значимого содержания получает пустой `codes`.
3. Каждый код подкреплён **дословной цитатой** из своего фрагмента: копируй
   текст буквально, не исправляй и не сокращай слова.
4. `rationale` — почему этот код, а не соседний. При сомнении между кодами
   следуй правилу при сомнении из кодбука и назови его.
5. Несколько кодов на фрагмент разрешены: реплика часто называет и риск, и
   способ проверки. Один код на мысль, без дублей.
6. `order` — `prompted`, если **содержание именно этого кода** уже назвал
   интервьюер в этом блоке или раньше; иначе `spontaneous`. Семья кода
   подсказкой не считается: слово «риски» в вопросе не делает подсказкой
   каждый код про риск, если сам код называет другое содержание.
7. `scenario` — `real` или `imaginary`, только если код отвечает на вопрос про
   конкретный случай (14Т-б); иначе `null`.
8. `reliability` — 1–3: насколько код следует из текста. 3 — категория названа
   прямо; 2 — следует из смысла, но с оговоркой; 1 — держится на догадке.
9. `interpretation` — прочтение искажённого или оборванного места реплики.
   Цитату это не заменяет: в `quote` остаётся дословный текст.
10. `interpretation_only = true`, если смысл кода восстановлен **только**
    догадкой, а не текстом. Тогда `reliability` не выше 1.
11. Не добавляй сведений, которых нет в реплике: ни фактов, ни оценок.

## Формат ответа

Верни один JSON-объект без пояснений и без markdown-обёртки:

```json
{
  "fragments": [
    {
      "fragment_id": 42,
      "codes": [
        {
          "code": "R5",
          "quote": "дословный срез фрагмента",
          "rationale": "почему этот код",
          "order": "spontaneous",
          "scenario": null,
          "reliability": 3,
          "reliability_note": "категория названа прямо"
        }
      ],
      "interpretation": null,
      "interpretation_only": false
    }
  ]
}
```

Для `OTH` добавь в объект кода поле `"oth_description": "что именно значимо"`.
