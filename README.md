# Анализатор интервью

Тематический анализ расшифровок интервью: транскрипт, размеченные фрагменты,
дерево тем с насыщением, отчёт. Цель и границы — `MANIFEST.md`, правила работы —
`CONSTITUTION.md`, этапы — `PLAN.md`.

## Установка

```bash
uv sync
```

Менеджер зависимостей только `uv`. Виртуальное окружение — `.venv` в корне, не коммитится.

## Команды

| Команда | Назначение |
|---|---|
| `uv run pytest -q` | Тесты (реальные данные — только при заданных переменных окружения) |
| `uv run ruff check .` | Линт |
| `uv run ruff format .` | Форматирование |
| `uv run mypy src` | Проверка типов |
| `uv run qa-pipeline --help` | Список команд пайплайна |

Подкоманды `qa-pipeline`:

| Команда | Назначение |
|---|---|
| `load-codebook [книга] [--reload]` | Обязательные листы книги, темы, словарь замен |
| `load-project [книга]` | Необязательные листы: лексикон, маркеры, интервью, роли, золотой набор, факты |
| `init-interview <R01.txt> --group "Не торгующие"` | Определить роли по числу слов и записать интервью |
| `load-transcript <R01.txt> [--interview-id] [--group]` | Разобрать транскрипт, псевдонимизировать, собрать реплики |
| `review-terms` | Утвердить или отклонить кандидатов новых терминов |
| `export-golden-sample [--n 40] [--interview-id] [--output]` | Выгрузить реплики L1 для ручной нормализации |
| `import-golden [файл]` | Загрузить заполненный золотой набор |

Значения групп и их алиасы задаются в `config.yaml` (секция `groups`); статусы лексикона —
в секции `lexicon_status_map`. Схема листов рабочей книги (лист -> колонка -> тип) —
в секции `workbook`.

## Структура данных

Каталог `data/` не коммитится (`.gitignore`) и не попадает в логи.

```
data/
  inputs/                     входные файлы
    Rabochaya_kniga_proekta_v4.xlsx   рабочая книга проекта (путь: paths.workbook)
    transcripts/              транскрипты, имя файла = код респондента (R01.txt)
  db/interviews.db            SQLite (путь: paths.db)
  backups/                    копии БД перед миграцией
  cache/                      кэш LLM
  exports/                    выгрузки
  golden/golden_sample.xlsx   золотой набор для ручного L2
```

Пути задаются в `config.yaml` (`paths:`) и создаются автоматически при запуске команд.
Таблица «имя -> код» хранится вне репозитория, путь — переменная окружения `NAMES_MAP_PATH`.
Секреты — только в `.env` (образец: `.env.example`).

## Данные и приватность

- Имена заменяются кодами при загрузке; таблица соответствия не коммитится.
- Тексты реплик не пишутся в логи — только идентификаторы, размеры и хеши.
- Реплики с признаком `pii_flag` (телефон, e-mail, длинные числа) помечаются для ручной
  проверки, но не блокируют загрузку; ложные срабатывания на денежных суммах ожидаемы.
