# Разметка границ фрагментов в реплике

Ты делишь реплику респондента на смысловые фрагменты. Реплика уже прошла
нормализацию (L2): текст не меняется, ты только указываешь, где кончается
одна мысль и начинается другая.

## Реплика

Номер: {utterance}
Вопрос интервьюера, на который она отвечает (может быть пустым): {question}

Текст L2 (не меняй его):

{text}

## Границы, предложенные кодом

Код уже нашёл места, где меняется тема: термины, исправления ASR, выражения
неуверенности. Это подсказка, а не обязательные границы.

{hints}

## Правила

1. Фрагмент — одна мысль, обычно 1-4 предложения. Слишком крупный фрагмент
   трудно кодировать, слишком мелкий теряет контекст.
2. Границы задаются **смещениями в символах** от начала текста L2: `start`
   включает символ, `end` не включает. Python-срез `text[start:end]` должен
   дать ровно текст фрагмента.
3. Фрагменты идут по порядку и **не пересекаются**. Между ними не должно быть
   пропусков: вместе они покрывают весь текст.
4. Не начинай и не заканчивай фрагмент внутри слова. Пробелы и знаки
   препинания на стыке относи к предыдущему фрагменту.
5. Не переписывай текст, не исправляй опечатки, не расставляй пунктуацию.
   Твоя работа — только границы.
6. Если реплика короткая и содержит одну мысль, верни один фрагмент,
   покрывающий весь текст.

## Пример

Реплика `Я попробовал, но не уверен. Дальше не подключал.` (длина 44)
даёт два фрагмента: `{"start": 0, "end": 26}` и `{"start": 26, "end": 44}`.

## Формат ответа

Верни один JSON-объект без пояснений и без markdown-обёртки:

```json
{
  "fragments": [
    {"start": 0, "end": 26},
    {"start": 26, "end": 44}
  ]
}
```
