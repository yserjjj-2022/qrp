# PLAN: этапы MVP

Версия 0.1. Каждый этап получает свой SPEC. Порядок фиксирован, но состав уточняется после первого транскрипта.

| Этап | Результат | Условие готовности | Нужен ли транскрипт |
|---|---|---|---|
| M0. Каркас | Репозиторий, окружение, схема БД и миграции, загрузка кодбука из приложения Б, YAML-дерево тем, интерфейсы `llm/` и `vectors/` с заглушками, CI-проверки локально | Загрузка даёт в БД 42 кода с атрибутами, тесты проходят без сети | Нет |
| M1a. Разбор и сборка реплик | Парсер транскрипта, псевдонимизация (роли, коды), фильтр шаблонов (`pii_flag`), сборка реплик с бэкканалами | Первый транскрипт разобран; текст не теряется; дублей нет | Да |
| M1b. Лёгкая нормализация (L2) | Детерминированный проход, нормализация моделью, автопроверки, кэш LLM, журнал изменений | Золотой набор принят; маркеры неуверенности, числа и отрицания сохранены на 100 % | Да |
| M1c. Привязка и сегментация | Привязка реплик к вопросам гайда, `prior_interviewer_turn_id`, сегментация L2 на фрагменты | Фрагменты равны срезам L2; распределение по вопросам проверено вручную | Да |
| M2. Кодирование | Промпты, структурированный вывод, проверка цитат, запись прогонов, лимиты, признак «спонтанно / по подсказке» | Нет аннотаций с несуществующей цитатой; повторный прогон воспроизводим | Да |
| M3. Эмбеддинги | Векторы фрагментов, поиск похожих, кластеризация фрагментов OTH, предложения новых кодов | Поиск похожих работает на фрагментах; кластеры выводятся для ревью | Да |
| M4. Дерево и дашборд | Агрегация по дереву, статусы листьев, показатели насыщения, страницы дашборда | Дашборд показывает заполнение дерева и кривые насыщения | Да |
| M5. Ревью и отчёт | Очередь проверки, ручные правки, сборка отчёта (графики плюс текст по числам) | Отчёт собирается одной командой, числа сверены с БД | Да |

Принципы последовательности: сначала данные и проверяемость, потом визуализация. Дашборд не пишется, пока нет надёжных аннотаций.
